# Results — EUR-Lex case study

> **These numbers are an example of the framework in use, not its product.**
> They belong to one specific corpus: 363 copyright documents from EUR-Lex, in English,
> evaluated on 50 question–answer pairs. **The winner of each stage holds for that corpus and
> should not be extrapolated to another domain** — that is precisely the argument of this work.
> What is reusable is the pipeline that produced them: see [`../README.md`](../README.md).

Everything in this folder is regenerated by
[`rag-eval/notebooks/03_results.ipynb`](../rag-eval/notebooks/03_results.ipynb) from each
experiment's `eval_metrics.json`.

## At a glance

| | P+R |
|---|---|
| Baseline (naive RAG) | 0.756 |
| "SOTA" stack from the literature | 1.095 |
| **Configuration found empirically** | **1.203** |

The winning configuration on this corpus: `bge-m3` · fixed 256-token chunking · MMR with
k=10 · no query expansion · cross-encoder reranking with `bge-reranker-v2-m3` and k=10.

Full walkthrough, including the two stages that contributed nothing:
